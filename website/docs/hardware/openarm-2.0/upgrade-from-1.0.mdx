# Upgrade from 1.0

If you already have an OpenArm 1.0, you don't need a complete 2.0 kit to upgrade.
The arm structure, motors, and electronics are the same in 1.0 and 2.0.
The upgrade replaces the gripper with the [2.0 gripper](./gripper.mdx) and swaps the J5 bracket.

This page lists only the parts you need to order for the upgrade.
Quantities are for a bimanual setup (right and left arm), the same as the [OpenArm 2.0 BOM](./general.mdx#manufacturing-information).

## What changes

| Part | 1.0 | 2.0 |
|---|---|---|
| Gripper | Linkage-driven parallel gripper | Compact gripper with an in-hand camera |
| J5 bracket | `J5_A` (`MVTUP-ASN-48P-5C724-L`) | `J5_A_rotate90` (`MVTUP-ASN-4EW-3BJ7T-L`) |
| J3-J4 cover and J4 cable holders | 1.0 version | 2.0 version (3D printed) |
