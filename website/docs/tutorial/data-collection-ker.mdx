# Data collection with KER

OpenArm KER is a motorless leader arm that enables intuitive operation of OpenArm 2.0.

<BlockImage src="tutorial/data-collection-ker/ker-how-to-wear.jpg" alt="OpenArm KER" width="90%" />

## Prerequisites
- Foot pedal (required for data collection)
- OpenArm KER

The Foot pedal is used to control the data collection. OpenArm KER is used to control the robot arms.

### Core Repositories
- **[openarm_ker](https://github.com/enactic/openarm_ker)**: PC-side data reception library.
- **[dora-openarm-ker](https://github.com/enactic/dora-openarm-ker)**: dora-rs node implementation for the OpenArm KER.

## Setup

### Software setup

#### 1. Install system dependencies

```bash
sudo apt install libusb-1.0-0-dev
```

#### 2. Set up udev rules

```bash
echo 'SUBSYSTEM=="usb", ATTRS{idVendor}=="303a", MODE="0666"' | sudo tee /etc/udev/rules.d/99-m5stack.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

If the KER is connected, you can check the connection with the following command.

```bash
lsusb | grep 303a
```

`303a:4002` should appear in the output.

#### 3. Ping KER with the CLI

`openarm-ker-cli` is installed with the data collection software (see [Installing the data collection software](./setup.mdx#installing-the-data-collection-software)).
Run the following command with the virtual environment of `dora-openarm-data-collection` activated.

```bash
openarm-ker-cli ping
```
If you get a response like below, the connection is successful.

```
OpenArm KER   USB 303a:4002

  Firmware   v1.0.0
  Hardware   KER-v1.0.0
  Updated    2026-05-25
```

Also, you can check the data from the encoder with the following command.

```bash
openarm-ker-cli stream
```

Please push the green button on the KER display to start streaming the data. The encoder angles and the stream rate are shown in the terminal. Press `Ctrl+C` to stop.


## Teleoperation and Data Collection

After the setup, you can run the dataflow and start teleoperation / data collection with KER.

### Install the data collection software

Install the data collection software as described in [Installing the data collection software](./setup.mdx#installing-the-data-collection-software).

If you have already cloned `dora-openarm-data-collection` without `--recurse-submodules`, run `git submodule update --init --recursive` in the repository to fetch the nodes.

### How to wear KER

1. Connect the device to your PC using a USB Type-C cable.
2. The KER M5Stack display should turn on.

   <BlockImage src="tutorial/data-collection-ker/m5-turn-on.jpg" alt="Turn on M5Stack" width="60%" />

3. Attach the holderto the mounting plate. Make sure the holder is securely attached.

   <div style={{ display: 'flex', justifyContent: 'center', gap: '1rem', flexWrap: 'wrap' }}>
     <BlockImage src="tutorial/data-collection-ker/ker-mount.jpg" alt="Front view" width="49%" />
     <BlockImage src="tutorial/data-collection-ker/ker-attach.jpg" alt="Back view" width="49%" />
   </div>

### Run the dataflow

Run the following command in the `dora-openarm-data-collection` directory with the virtual environment activated.

```bash
dora run dataflow-ker.yaml --uv
```

Open the web UI at http://localhost:8000 same as VR teleoperation. The foot pedal works as a keyboard, so keep the web UI tab focused while you use the pedal.
The collected data is stored in `ker_data` by default, which is set as `DIRECTORY` of the `recorder` node in `dataflow-ker.yaml`.

<BlockImage src="tutorial/data-collection-vr/data-collection-start-quit.png" alt="Web ui" width="90%" />

After you start the dataflow, you can align the KER with the OpenArm by pulling the KER trigger. After the alignment, OpenArm will follow the movement of KER, and you can do teleoperation smoothly with KER.

During the data collection, you can use the foot pedal to control the start / stop / reset or success / failure of the data collection.

We recommend using a [3-button foot pedal from SANWA Supply](https://direct.sanwa.co.jp/ItemPage/400-MA179).

<BlockImage src="tutorial/data-collection-ker/footpedal.jpg" alt="Foot pedal" width="90%" />

Button mapping:

| Button | Start panel | Recording panel |
| --- | --- | --- |
| left (a) | - | fail (long press: cancel) |
| middle (b) | quit (long press: start / pause arms) | quit (long press: start / pause arms) |
| right (c) | start (long press: skip task) | success |

A long press means holding the button for 1 second or longer.
You can stop the arms temporarily and start them again by long-pressing the **middle(b)** button or by pressing the **Pause Arm** / **Start Arm** button on the web UI.
If you use a different foot pedal, please check the button mapping and map the buttons to a,b,c accordingly.

After you start the data collection, you can see the start or skip panel on the web UI. You can start the data collection by pressing the **right(c)** button.

<BlockImage src="tutorial/data-collection-ker/data-collection-start.jpg" alt="Data collection start quit" width="80%" />

After the data collection is started, you can see the success or fail panel on the web UI.

Press the **left(a)** button to mark the data collection as fail, or press the **right(c)** button to mark it as success.
To discard the current episode without saving it, long-press the **left(a)** button.
If you press success or fail within 1 second after starting with the pedal, it is ignored to prevent accidental double presses.

<BlockImage src="tutorial/data-collection-ker/data-collection-success-fail.jpg" alt="Data collection fail success" width="80%" />

Also, you can press the **middle(b)** button to quit the data collection at any time. The episode being recorded is saved as a failure.

### Troubleshooting
If you see the following screen, check the possible causes below.

#### 1. If the `ERR` bar is displayed

Possible causes:

* Check that all cables are connected securely.
* Make sure the IC is properly seated and not loose.
* Inspect the connectors and PCB for poor contact or damaged pins.

<BlockImage src="tutorial/data-collection-ker/cable-connection.jpg" alt="Cable connection" width="90%" />

#### 2. If Jump Detect is displayed

<div style={{ display: 'flex', justifyContent: 'center', gap: '1rem', flexWrap: 'wrap' }}>

Please write the zero position again. See the [Calibration workflow](/hardware/openarm-ker/calibration-workflow) for details.


First, put the KER in the Box and fix the position of the KER with screws.

<BlockImage src="tutorial/data-collection-ker/ker-zero-pose.jpg" alt="Zero position" width="90%" />

Then, turn on the KER by connecting the USB cable, and press the gray button(Zero Reset All) on the KER display.

<BlockImage src="tutorial/data-collection-ker/ker-display.jpg" alt="Zero reset" width="90%" />

Pop up window will appear on the display. Please select `Yes` and press the button to write the zero position.

<BlockImage src="tutorial/data-collection-ker/ker-calib.jpg" alt="Zero reset popup" width="90%" />
